# Expresso Planalto — Pouso Alegre

## Sobre o projeto

O Expresso Planalto é um projeto de desenvolvimento web que apresenta uma plataforma institucional para a empresa de transporte coletivo Expresso Planalto, localizada em Pouso Alegre – MG.

O site foi desenvolvido com o objetivo de facilitar o acesso dos usuários às informações da empresa, oferecer canais de atendimento e apresentar uma área demonstrativa de recarga online.

O projeto possui uma interface moderna, responsiva e intuitiva, priorizando a facilidade de navegação e a experiência do usuário.

## Objetivos

1. Apresentar a empresa e seus serviços.

2. Facilitar o contato entre passageiros e empresa.

3. Disponibilizar uma área demonstrativa de recarga de passes.

4. Permitir a navegação entre páginas independentes.

5. Oferecer uma interface adaptável a computadores e dispositivos móveis.

## Observações importantes

As funcionalidades de login, cadastro e recarga presentes nesta versão são demonstrativas e executadas no próprio front-end.

O projeto ainda não possui integração com banco de dados, autenticação real de usuários ou processamento financeiro.

Para utilização em ambiente de produção, será necessária a implementação de um back-end, armazenamento seguro de dados e integração com serviços de pagamento.

## Considerações finais

O projeto Expresso Planalto busca demonstrar a aplicação prática dos conhecimentos de desenvolvimento web, utilizando HTML5, CSS3 e JavaScript na construção de uma plataforma institucional.

A estrutura modular das páginas e a utilização de arquivos compartilhados facilitam a manutenção, organização e evolução do sistema.
