# Expresso Planalto — Pouso Alegre

Site organizado em três páginas HTML independentes, conectadas pela navegação: `index.html`, `recarga-online.html` e `fale-conosco.html`.

Abra `index.html` no navegador para iniciar. Os arquivos `style.css` e `script.js` são compartilhados pelas páginas.

Observação: login, cadastro e recarga são demonstrações front-end, sem autenticação de servidor ou processamento financeiro real.
